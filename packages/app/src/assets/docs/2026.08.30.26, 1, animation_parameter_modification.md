`useMotionTimeline` now accepts either a keyframe array or a factory that returns one, and it restarts the sequence when that first argument changes.

**Array or factory.** The first argument is `TimelineSource`: `TimelineItems[] | (() => TimelineItems[])`. A factory is called inside the effect, so a **stable** function (same reference) is invoked once. A new function or a new array starts a new run.

**Restart on change.** The effect depends on that first argument. When it changes, in-flight Motion playbacks are `stop()`’d, the loop is cancelled, and the timeline starts again from the new items.

Existing array callers (including `TimelineExample`) stay valid. For a factory, keep the function stable:

```tsx
const scope = useMotionTimeline(TIMELINE_ITEMS, Infinity);
// or
const scope = useMotionTimeline(getTimelineItems, Infinity);
```

Inline `() => [...]` on every render will restart every render. Use a module-level function or `useCallback`.
